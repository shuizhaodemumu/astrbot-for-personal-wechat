# v0.2.0 · 按群选择人格与群名显示

## 新增功能

- 插件配置按微信群名称展示，每个群可以独立选择已创建的人格。
- 群名在插件启动或保存时从本机微信桥接读取；读取失败保留原名称，匹配始终使用群 ID。
- 保存配置后自动重载插件并应用人格，日常切换无需重启整个 AstrBot。
- 默认在切换人格时新建对话，保留旧会话；也可关闭此选项以继续原上下文。
- 同步群配置与当前会话的人格选择，处理旧会话覆盖群默认人格的问题。
- 原先共享配置的群会获得独立配置，避免影响其他群或平台。

## 从 0.1.0 升级

1. 备份当前插件目录和 AstrBot 数据。
2. 将附件 `astrbot_plugin_native_wechat-v0.2.0.zip` 解压，把其中的插件文件覆盖到 `data/plugins/astrbot_plugin_native_wechat/`。务必包含新增的 `_conf_schema.json`。压缩包不包含微信桥接程序，已有桥接服务继续使用。
3. 重启一次 AstrBot，刷新管理页面。
4. 进入 **插件 → AstrBot for Personal WeChat → 配置 → 微信群人格**，按群名选择人格并保存。
5. 用另一个微信号在对应群中 @机器人，验证名字和回复风格。

首次部署仍需按仓库 `docs/DEPLOYMENT.md` 配置本机桥接、聊天模型和群允许列表。添加人格配置卡片不会授权新的回复群。
